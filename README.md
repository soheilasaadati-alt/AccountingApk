# دفتر من — حسابداری شخصی (اندروید)

برنامه نیتیو اندروید با Kotlin، Jetpack Compose و Room.
تمام داده‌ها در دیتابیس خود برنامه روی گوشی ذخیره می‌شوند و به اینترنت نیازی ندارد.

**طراحی و توسعه: سهیلا سعادتی**

## امکانات
- ثبت هزینه و درآمد/واریزی با دسته‌بندی، حساب بانکی، تاریخ شمسی و توضیح
- گروه‌های هزینه و درآمد قابل تعریف (نام، آیکن، رنگ)
- اقساط ماهانه (بیمه ماشین، قسط کارت، شهریه و...): فقط عنوان، مبلغ هر قسط و تاریخ سررسید اولین قسط.
  تعداد اقساط اختیاری است (خالی = هر ماه تکرار می‌شود). پرداخت هر قسط خودکار به‌عنوان هزینه ثبت می‌شود.
- یادآور سررسید: برای هر قسط انتخاب می‌کنی همان روز، یا ۱ تا ۷ روز قبل اعلان بیاید
- چند حساب بانکی با موجودی لحظه‌ای، جمع واریزی‌ها و برداشت‌ها
- گزارش ماهانه با نمودار دایره‌ای هزینه‌ها

## یادآور اقساط
- هر روز حدود ساعت ۹ صبح (با WorkManager) بررسی می‌شود و برای قسط‌هایی که یادآور دارند اعلان نمایش داده می‌شود:
  از چند روز قبل از سررسید تا حداکثر ۷ روز بعد، تا وقتی پرداختش را در برنامه ثبت نکرده‌ای.
- اندروید ۱۳ به بالا هنگام ذخیره اولین قسط با یادآور، مجوز اعلان را می‌پرسد.
- زمان دقیق اعلان ممکن است به‌خاطر حالت صرفه‌جویی باتری چند دقیقه یا بیشتر جابه‌جا شود.

## ساخت و اجرا
1. Android Studio نسخه Koala (2024.1) یا جدیدتر را نصب کن.
2. پوشه `DaftarMan` را با File > Open باز کن و صبر کن Gradle sync تمام شود
   (بار اول از اینترنت وابستگی‌ها را دانلود می‌کند).
3. گوشی را با USB Debugging وصل کن (یا امولاتور بساز) و Run را بزن.
4. برای فایل APK قابل نصب: Build > Build Bundle(s) / APK(s) > Build APK(s).
   برای انتشار: Build > Generate Signed Bundle / APK.

نکته: ساختار دیتابیس نسبت به نسخه قبلی عوض شده (نسخه ۲). اگر نسخه قبلی را روی گوشی نصب کرده بودی،
نصب این نسخه روی آن اطلاعات قبلی را پاک می‌کند؛ اگر داده مهمی داری قبلش یادداشتش کن.

نکته: فایل `gradle-wrapper.jar` در این بسته نیست. اگر Android Studio درباره Gradle wrapper پرسید،
تأیید کن تا خودش ایجاد شود (توزیع Gradle 8.7 در `gradle-wrapper.properties` تعریف شده است).

## ساختار
- `data/` موجودیت‌ها (Account, Category, Txn, Loan)، DAOها و دیتابیس Room
- `reminder/` زمان‌بندی روزانه و اعلان یادآور اقساط
- `util/` تقویم شمسی، فرمت اعداد فارسی، محاسبات (موجودی، اقساط)
- `MainViewModel.kt` وضعیت برنامه و عملیات ذخیره/حذف
- `ui/` تم، کامپوننت‌ها، صفحه‌ها و فرم‌ها

## فونت وزیرمتن (اختیاری)
فایل‌های Vazirmatn را در `app/src/main/res/font` بگذار و در `ui/Theme.kt` مقدار `AppFont` را مطابق توضیح همان فایل تغییر بده.

## پشتیبان‌گیری
`allowBackup` فعال است؛ با روشن بودن Google Backup روی گوشی، دیتابیس همراه برنامه پشتیبان‌گیری می‌شود.

## ساخت روی GitHub Actions
فایل `.github/workflows/build.yml` اضافه شده است. با هر push، فایل APK دیباگ ساخته می‌شود و
از تب Actions > آخرین اجرا > Artifacts قابل دانلود است.
این پروژه فایل‌های `gradlew` و `gradle-wrapper.jar` ندارد، پس workflow به‌جای `./gradlew` از `gradle` استفاده می‌کند.
اگر خودت `./gradlew` می‌خواهی، یک بار روی کامپیوتر `gradle wrapper --gradle-version 8.7` را اجرا کن و فایل‌های ساخته‌شده را commit کن.
